# 短描述（仅功能）

**Mod 名**：`Rose Winters (RE8) - Argon Female NPC Replacer`

**一句话简介**（mod 卡片用）：
```
Resident Evil Village's Rose Winters replaces the Argon female NPC models in X4: Foundations.
```

**功能列表**（描述开头用）：
```
Rose Winters (RE8) - Argon Female NPC Replacer

Replaces the Argon female NPC models in X4: Foundations with Rose Winters from
Resident Evil Village (Shadows of Rose).

- Custom model, textures and materials for Rose Winters
- Built on the vanilla shared skeleton and animation set, so all animations,
  look-at and hand attachment points work normally
- No game files modified; enable or disable at any time and saves stay valid
- Shader-only overlay layers (eye lens shells) removed so the real eyeballs show

Note: this build replaces every Argon female appearance pool, so all Argon women
are Rose rather than the usual random one in four.

Requires X4: Foundations 9.00.
```
