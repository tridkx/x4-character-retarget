# 短描述（仅功能）

**Mod 名**：`Rose Winters (RE8) - Argon Female NPC Replacer`

**一句话简介**（mod 卡片用）：
```
Resident Evil Village's Rose Winters joins (or replaces) the Argon female NPC models in X4: Foundations.
```

**两个下载，两种形态**（文件名即配置）：
```
x4_rose_argon_add_v1.3.zip      -- 加入外观池（正常玩用这个）
x4_rose_argon_replace_v1.2.zip  -- 全部替换（测试 / 想满地图都是萝丝时用）
```

**功能列表**（描述开头用）：
```
Rose Winters (RE8) - Argon Female NPC Replacer

Brings Rose Winters from Resident Evil Village (Shadows of Rose) into
X4: Foundations as an Argon female NPC model. Two shapes, two files:

- x4_rose_argon_add_v1.3.zip (normal build) -- Rose joins the Argon female
  appearance pools as one more random candidate, about one in four of the women
  a job spawns. Every vanilla model stays, so the other Argon women keep their
  own faces, names and voices. Story and mission NPCs keep their vanilla
  appearance (they never come from a pool).
- x4_rose_argon_replace_v1.2.zip (test build) -- every Argon woman is Rose,
  story and mission NPCs included. Overrides other Argon appearance replacers.

Both: custom model, textures and materials; built on the vanilla shared
skeleton and animation set, so animations, look-at and hand attachment points
work normally; no game files modified, enable or disable at any time and saves
stay valid; shader-only overlay layers (eye lens shells) removed so the real
eyeballs show.

Requires X4: Foundations 9.00.
```
